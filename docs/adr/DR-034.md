# DR-034 — PB4 frontend toolchain and visual direction

- **Status:** Implemented; subject to the PB4 baseline gate.
- **Context:** PB4 requires React 18, TypeScript, Vite, Tailwind, Lucide, Axios,
  Recharts, React Router, strict TypeScript, ESLint, Vitest and Playwright.
  The specification does not prescribe their minor versions or visual system.
- **Decision:** The owner selected **“Dark SOC console (recommended)”**.
  Use a high-contrast navy security-operations shell, clear status colors,
  logical CSS/RTL support and accessible controls. Pin React/React DOM 18.3.1,
  React Router 7.18.5, Axios 1.21.1, Recharts 3.10.1, Lucide 1.72.0,
  TypeScript 6.0.3, Vite 7.3.8, its React plugin 5.2.0, Tailwind 3.4.19,
  ESLint 9.39.5, typescript-eslint 8.72.2, Vitest 5.1.0 and Playwright 1.65.0.
  `package.json` pins every direct dependency; `package-lock.json` records the
  exact resolved dependency graph and integrity hashes. The deployment/CI Node
  remains the Node 26.13.1 selected in DR-001; Node 22.22.2 or newer is the
  minimum for this toolchain. ESLint forbids raw HTML insertion.
- **Reason:** These versions satisfy the requested major versions and peer
  ranges. TypeScript 7 is outside typescript-eslint's supported range; Vite 7
  and Tailwind 3 are compatible with the selected toolchain. Recharts's
  `react-is` peer is pinned to React’s major. A scoped minimatch 11.0.8 override addresses a lint-time advisory; compatibility is verified by the lint suite. Avoiding raw HTML helps keep
  alert content inert.
- **Alternatives:** Light and dual themes; newer incompatible majors; unpinned
  or unhashed installs.
- **Consequences:** The lock must be updated deliberately and audited. Local
  frontend tests are not a substitute for real Compose/Playwright verification.
