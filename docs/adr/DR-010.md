# DR-010 — Redact test credentials at their source

- **Status:** Revised after PB1 review; the earlier decision to suppress pytest
  tracebacks and captured output is superseded.
- **Context:** A PB1-T07 malformed-Unicode test failed inside the HTTP client's
  encoder before reaching the application. Pytest's failure output exposed an
  ephemeral test password and Argon2 hash from the fixture's representation.
  No production credential was involved. The owner rejected the subsequent
  suppression of failure details as contrary to R-09.
- **Decision:** Run pytest with `--tb=short` and `--strict-markers`, retaining
  its normal failure summary and captured output. Remove the custom terminal
  summary hook. Generated test passwords, password hashes and other credential
  values held in fixtures use the test-only `Redacted` wrapper, whose `repr` and
  `str` do not reveal the value. It is a separate object, not a string subclass:
  pytest's string-diff machinery can otherwise reveal the underlying text even
  when a subclass overrides its representation. Test request, database and
  subprocess boundaries explicitly unwrap values; the test HTTP client unwraps
  copies of request data without changing the original fixtures. Assertions
  checking for leakage report the context without echoing the suspect output.
- **Regression:** The subprocess test deliberately produces failing comparisons,
  a nested fixture failure, the malformed-Unicode encoder failure and an HTTP
  assertion failure. It checks that the test names, exception and assertion
  details, and captured diagnostic output remain visible, while generated test
  password and hash values do not appear. Additional tests verify request
  unwrapping and that the leak assertion actually fails on disclosure.
- **Limit:** The wrapper protects representations, not arbitrary serialization,
  explicit `reveal()` calls, or secrets a third-party exception or log prints.
  Tests must use throwaway credentials, unwrap only at integration boundaries,
  and avoid putting revealed values in assertions or captured output. Never use
  real credentials as test data.
