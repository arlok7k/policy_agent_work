# DR-010 — Redacted automated test failure output

- **Status:** Accepted by the implementation agent; no security rule is relaxed.
- **Context:** A PB1-T07 test failed inside the HTTP client's JSON encoder before
  reaching the application. Pytest's default traceback printed an ephemeral
  test account's generated password and Argon2 hash from the fixture's repr.
  No production credential was involved. The test was corrected to transmit
  escaped JSON, and the same test passed afterward.
- **Decision:** Automated pytest runs suppress tracebacks and captured output
  and print failing test names without parameter values. Tests still execute,
  fail normally with a nonzero exit, and are not skipped or weakened. A
  subprocess regression test verifies both failure visibility and redaction.
- **Consequence:** The failing test and phase remain visible, but exception
  details are not available in normal CI output. Diagnose using a deliberately
  nonsecret reproduction or a protected debugger; do not enable verbose
  tracebacks against tests containing credentials or disclose their output.
  This trades convenience for the spec's no-secret/no-hash logging requirement.
