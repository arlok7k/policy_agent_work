# DR-004 — Starlette test-client dependency

- **Status:** Accepted for PB1.
- **Context:** The first configuration test run passed, but Starlette 1.10.0
  warned that its `httpx` test-client fallback is deprecated and recommends
  `httpx2` instead.
- **Decision:** Replace the direct test dependency on HTTPX 0.28.1 with the
  pinned and hash-locked `httpx2` 2.16.0 used by Starlette's test client.
- **Alternatives:** Keeping the fallback would retain a known deprecation;
  suppressing the warning would hide the compatibility risk.
- **Consequences:** Re-run the full PB1 checks and dependency/secret scans after
  regenerating the lock. This changes test tooling, not the public API.
