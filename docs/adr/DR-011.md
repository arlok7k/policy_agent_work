# DR-011 — API key credential representation

- **Status:** Accepted by the implementation agent as an implementation of the
  DR-009 transport and service-principal boundary; its owner approval remains to
  be confirmed.
- **Decision:** An issued key is `soc_<random UUID hex>.<32-byte random URL-safe
  value>`. The prefix is an indexed nonsecret locator; the independent secret
  is returned only at issuance. The database stores an HMAC-SHA-256 digest of
  the entire token, domain-separated from session/CSRF/throttle digests with
  the existing independently provisioned session-signing secret. Verification
  compares digests in constant time after checking expiry, revocation and owner
  activity using database time.
- **Consequences:** The service cannot reconstruct a lost key. Rotating the
  signing secret invalidates all current sessions and keys, and resets the
  effective login-throttle buckets; operators must plan reissuance and rate-
  limit protection during rotation. The token is never written to audit or
  ordinary logs, and its response is explicitly `no-store`.
